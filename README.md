# Camp180 Python 2D Game Development Course
A beginner-friendly journey into 2D game development using Pyton, Pygame, and creativity - all while helping fund coding camps for underserved youth.

## About This Course
This repository is part of the **Camp180 Python 2D Game Development Course**, a 6-month guided roadmap designed to take absolute beginners from zero to confident game developers - using only free tools and a love for building.

- **Learn** coding fundamentals.
- **Practice** with bite-sized projects.
- **Build** your own 2D games.
- **Give back** by helping sponsor Camp180 coding campers!

## What's Inside
- 'journal.md' - Your downloadable (printable) coding journal
- Weekly lesson folders
- Starter templates, student projects, and bonus challenges
- Github tips amd cpllaboration coding resources

> Each commit you make is one step closer to your own game

## Tools You'll use
- Python 3.11+
- VS Code
- Pygame
- Git & Github
- Turtle graphics
- Game design logic

## Course Layout
| Module | Theme                       | Focus                                |
|--------|-----------------------------|--------------------------------------|
| 0      | Setup & Orientation         | Python, VS Code, terminal            |
| 1      | Python Basics               | Variables, loops, conditionals       |
| 2      | Functions & Data Structures | Lists, functions, dectionaries       |
| 3      | VS Code Deep Dive           | Debugging, file navigation           |
| 4      | GitHub & Collaboration      | Version control, shared repositories |
| 5      | Turtle Graphics             | Drawing, creativity                  |
| 6      | Pygame Intro                | Sprites, movement                    |
| 7      | Player Interaction          | Sound, collisions                    |
| 8      | Game Mechanics              | UI, powerups, AI                     |
| 9      | Modular Game Design         | File structure, reusable code        |
| 10     | Final Game Project          | Build, polish, publish               |
