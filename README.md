# Camp180 Python 2D Game Development Course
A beginner-friendly journey into 2D game development using Pyton, Pygame, and creativity - all while helping fund coding camps for underserved youth.

## About This Course
This repository is part of the **Camp180 Python 2D Game Development Course**, a 6-month guided roadmap designed to take absolute beginners from zero to confident game developers - using only free tools and a love for building.

- **Learn** coding fundamentals.
- **Practice** with bite-sized projects.
- **Build** your own 2D games.
- **Give back** by helping sposor Camp180 coding campers!

## What's Inside
- 'journal.md' - Your printable or digital coding journal
- Weekly lesson folders
- Starter templates, student projects, and bonus challenges
- Github tips amd cpllaboration coding resources

> Each commit you make is one step closer to your own game

## Tools You'll use
- Python 3.11+

- Git & Github
- Turtle graphics
- Game design logic
